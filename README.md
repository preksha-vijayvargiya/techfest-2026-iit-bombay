An immersive, futuristic web portal for **Techfest 2026, IIT Bombay** (Task 4 Submission). Built with cutting-edge visual design, 3D WebGL graphics powered by Three.js, dynamic particle canvases, interactive event registries, and comprehensive accommodation booking flows.

---

## ✨ Features

- **🌐 3D Interactive Earth & Space Engine:** Built using Three.js with realistic textures, atmosphere rendering, orbiting nodes, and responsive drag/rotate controls.
- **✨ Dynamic Constellation Canvas:** Background interactive particle physics system with cursor attraction/repulsion.
- **🏛️ Core Pillars & Festival Divisions:**
  - **International Robowars:** High-octane combat robotics arenas.
  - **Certified Workshops:** GenAI/LLMs, Humanoid Robotics & ROS2, Ethical Hacking, Drones, Quantum Computing with Qiskit, and TinyML.
  - **Competitions Hub:** Boeing Aeromodelling, International Coding League, Meshmerize Line Follower, Cozmo Clench, and Technorion.
  - **World Keynotes:** Distinguished addresses by Nobel Laureates, Turing Award winners, ISRO leadership, and tech innovators.
  - **Ignite Initiative:** National college student innovation network and CA partnerships.
- **🏨 IIT Powai Accommodation Portal:**
  - Tariff breakdown for Male, Female, and Squad suites.
  - Built-in booking request modal with validation and instant confirmation.
  - Comprehensive accommodation FAQs and guidelines.
- **🔍 Quick Search & Shortcuts:** Global search modal with keyboard navigation (`Ctrl+K` / `Cmd+K`).
- **📱 Fully Responsive Design:** Fluid typography and glassmorphism UI styled for desktop, tablets, and mobile screens.

## 🚀 Getting Started

No build step or Node.js environment is required. You can run the portal directly in any modern browser:

### Option 1: Direct File Launch
Simply clone this repository and double-click `index.html`:
```bash
git clone https://github.com/preksha-vijayvargiya/techfest-2026-iit-bombay.git
cd techfest-2026-iit-bombay
# Open index.html in your default web browser
```

### Option 2: Local HTTP Server (Recommended)
Using Python:
```bash
# Python 3
python -m http.server 8000
```
Then navigate to `http://localhost:8000` in your browser.

Or using VS Code Live Server extension:
- Right-click `index.html` and select **"Open with Live Server"**.
